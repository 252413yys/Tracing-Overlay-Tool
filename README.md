
Windows 桌面悬浮透明图片工具
## 简介
Python+Win32 API+Ai/deepseek实现的悬浮参考图工具，支持 PNG 透明通道，适应于绘画描图、对照参考等场景。

## 功能
- 多图片同时悬浮，自由拖动
- Multiple floating images at the same time, free to drag
- 缩放1%-150%、调节透明度
- Scale from 1% to 150%, adjust transparency
- 窗口置顶、鼠标穿透锁定
- Window topmost, mouse pass-through lock
- 截图/录屏隐藏窗口
- Hide window from screenshots and screen recording
- 一键隐藏/关闭悬浮图
- One-click hide/close floating images

## 系统
仅支持 Windows
