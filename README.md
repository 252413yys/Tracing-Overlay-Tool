# 绘画描图图片悬浮器
Windows 桌面悬浮透明图片工具

## 简介
Python+Win32 API 实现的悬浮参考图工具，完美支持 PNG 透明通道，适应于绘画描图、对照参考等场景。

## 功能
- 多图片同时悬浮，自由拖动
- 缩放1%-150%、调节透明度
- 窗口置顶、鼠标穿透锁定
- 截图/录屏隐藏窗口
- 一键隐藏/关闭悬浮图

## 系统
仅支持 Windows
